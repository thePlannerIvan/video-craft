# 素材真实，表达形式开放

真实素材优先提供证据，不强制每一屏保持截图形态。先判断本段是在“证明发生过什么”还是“帮助理解关系”，也可以两者结合。

| 当前责任 | 合适的来源与处理 |
|---|---|
| 展示真实界面、数据、产物或操作 | 查原始素材，必要时忠实复刻无法获取的呈现；复刻必须标注身份，不冒充实录 |
| 解释关系、变化、系统、数量 | 用真实数据和已支持的语义设计图形、模型或动画；即使存在截图也可以抽象解释 |
| 创造情绪、隐喻或视觉体验 | 可用创作/生成素材，明确其创作身份；不将它当作真实事件的证据 |
| 既要证据又要理解 | 原物→局部提取/模型→变化→回到原物；数字、标签和来源保持可追溯 |

AI/工具流程可以用录屏、时间压缩、对话重现、信息流、状态模型或其他形式，不默认必须做聊天气泡。选择取决于哪种关系值得看见，而不是模板库存。

采集时读取真实画面，选能展示目标动作的连续区间；字幕/界面小字在成片尺寸可读。来源记在现有 production-plan/storyboard 的 media 项中，标记 original / replica / schematic / generated，避免另造一个素材总账。

原始宽高比保持准确；若需拆层、变形或重排，应让观众能区分原始证据和解释层。按已有隐私约定使用脱敏副本，缺素材明确指出，不能通过复刻或生成掩盖不存在的结果。
