# 0002 · 四档视觉语法与构建期统一画面质量门禁

**Status**: accepted (partially superseded by ADR-0005)

我们决定废除过去强制逐元素照搬静态参考页的旧闸门，改为由视觉分拍表按口播语义驱动的四档视觉语法（`talk-only` / `logic-diagram` / `theory-board` / `demo-footage`），并把防小字、防死静、画框避让、实战踩坑拦截与实机录屏专项检查合并成一条按档分流的构建期质量门禁。

## Considered Options

- **继续强制搬运静态参考页**：导致模型机械复刻 PPT 框线与碎字，产生「画面精致但手机端看不清字」的信息过载。
- **完全放飞自由发挥、不做机械校验**：模型容易退回打字机效果、把字写小、停在同一画面超过 10 秒，或把实机百兆录屏直接塞进浏览器导致卡死发糊。

## Consequences

- `demo-footage` 段预览用轻量代理、交付由视频合成器从高清原录屏直切拼合，且免受 32px 字号与网页静止告警误伤。
- 人物轨继续独立于画面成片，既满足多轨后期自由度，又根治了实机演示视频与图形动效混排时的兼容断点。
