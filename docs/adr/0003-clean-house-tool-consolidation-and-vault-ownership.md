# 0003 · 清理历史包袱、脚本十合一收口与风格库归口边界

**Status**: accepted

我们决定彻底移出已退役的旧实现存档、数学动画子工具、已迁往 `video-manager` 的风格提取写入工具及零引用孤立脚本；将剩余八十余个脚本收口为约十个顶层公共入口并把底层共享件沉入 `helpers/_internal/`，同时保留轻量只读解析与开源默认回退能力。

## Considered Options

- **推倒重写整套工具目录**：风险过高，容易破坏已验证稳定的逐字剪辑、实测时间轴、文章优先字幕与交付核验底座。
- **保留顶层 80 多个脚本仅改文档**：模型上下文仍被大量内部实现与过时路径污染，难以一眼辨认唯一入口。

## Consequences

- 模型默认视野只剩约十个高内聚顶层命令行入口与约十一份手册，噪音大幅降低。
- 公开 GitHub 仓库在未安装私有风格库或本地制片总控时仍可自动回退内置默认规范独立跑通；第三方 MIT 上游版权正文迁移保留在开源声明文件中。
