# 风格规范（动效）

> 第 2 步定风格，第 7 步读对应那一节。**本文件只管怎么动**：强调手段、运动方式、禁止项。
> 静态画面语法（色板、字号、构图、硬边、排版）归画面侧 `planners-ppt-hell` 的模板与风格文档；本文件不重复，只保证动效与之一致。
> 跨风格规则见 [author-spec.md](author-spec.md)。**路线只有 recompose 一条**：拿到原页后拆解重做，不存在"给原稿加动画"的流程。
> 上限：每种风格 ≤ 5 条，由 `helpers/spec_lint.py` 强制。元素级的特殊处理不进本文件（见文末）。
> 与外部通用动效原则（`hyperframes-creative` 等）冲突时，本节优先：那是通用建议，这里记的是作者判准。

## 风格清单

| slug | 风格 | 怎么认 | 参考项目 |
|---|---|---|---|
| `line-art` | 线稿 / 工程图 | 单一主体、黑白线稿、信息靠位置与刻度变化 | 手冲咖啡 |
| `business-report` | 商业报告 | 原页层级照搬、黑底、荧光条、巨型数字与判词、窗口/表格 | 三条片最新版、图拉斯 |
| `collage` | 拼贴 | 纸色与炭墨、终端命令条、拍立得/印章/胶带/红圈 | Research 与 Wayfinder |
| `concept-film` | 概念电影 | 一个镜头一个关系、抽象转空间动作、空间连续、真实与抽象并用 | 参考片：扩散模型 / Flow Matching |

> 证据说明：四种风格都来自实际成片或参考片，但每种目前只有一到两个项目，证据密度低于全局判准；出现新项目时补充证据，与新证据冲突则修订。

## line-art · 线稿 / 工程图

### S01 强调靠指针、刻度与字号

- 做法：强调通过指针角度、刻度位置、字号变化实现；不用颜色、外框、下划线、底纹。
- 证据：手冲咖啡 beat-02、beat-08
- 执行：judgment:看强调手段是否落在指针／刻度／字上

### S02 运动以指针、游标、连线生长为主

- 做法：主体运动限于指针摆动、游标沿轴移动、连线自绘、数值递增；不做整块飞入。
- 证据：手冲咖啡 beat-03、beat-04、beat-08
- 执行：judgment:确认每个运动都能对应到刻度或连线的变化

### S03 长段落保留主体做轻微演化

- 做法：口播没有新内容时，已画好的图形做小幅呼吸或漂移；主体始终在画面内，不整体退场。
- 证据：手冲咖啡 beat-08
- 执行：judgment:看长段落的主体是否一直在

## business-report · 商业报告

### S04 说到哪个对象，哪个对象获得主体位置

- 做法：口播逐个点名时，画面把对应对象放大或移到主体位置；不预先挤成一排小图标。
- 证据：三条片 V1 ch02、ch03；V3 ch04
- 执行：judgment:逐句看被点名对象是否获得主体位置

### S05 行与列按口播逐行点亮

- 做法：表格、清单、窗口内文本按口播顺序逐行变实；未提到的行保持可读但弱化。
- 证据：三条片 V2 ch03、ch04
- 执行：judgment:看逐行出现的顺序是否与口播一致

### S06 荧光色只做结构标记，不做强调

- 做法：荧光色用于标题条、状态条、结构线；不因口播提到某个词而让该元素变亮或加外框。
- 证据：三条片 V2 ch02、V3 ch02
- 执行：judgment:确认荧光色只出现在结构件上

### S07 强调靠字号、位置与判词层级

- 做法：强调用字号差、位置差和判词（结论句）的层级完成；不用外框、闪烁、抖动脉冲。
- 证据：三条片 V2 ch02、ch04
- 执行：judgment:看强调是否靠这三者完成

### S08 转场直切

- 做法：场景之间直切或极短交叉；不做大动作转场、不做整屏推拉。
- 证据：三条片全片
- 执行：judgment:看场景切换方式

## collage · 拼贴

### S09 入场是物理动作，每个动作有落点

- 做法：素材以甩落、砸印、贴胶带、划线等物理动作入场；每个动作有明确落点与停顿。
- 证据：Research 与 Wayfinder beat-02、beat-03
- 执行：judgment:看每个素材入场是否有动作与落点

### S10 自绘标记必须指向证据

- 做法：红圈、箭头、划线用于指向被引用的素材或数据；不画没有指向对象的装饰。
- 证据：Research 与 Wayfinder beat-02
- 执行：judgment:确认每个标记都指向具体对象

### S11 终端条以显影方式出现

- 做法：命令条先出容器，再显影文本，最后出现光标；文本按整段或逐字出现，不做飞入。
- 证据：Research 与 Wayfinder beat-00、beat-03
- 执行：judgment:看终端条的出现层次

### S12 段落切换允许整屏底色反转

- 做法：纸色与炭墨之间整屏反转用于分节；反转是结构手段，不用来强调某个词。
- 证据：Research 与 Wayfinder beat-03
- 执行：judgment:确认底色反转只发生在段落边界

### S13 纸张素材保留纸感，不裁齐

- 做法：拍立得、相纸、打印件保留边缘、投影与轻微倾斜；不裁成直角矩形对齐网格。
- 证据：Research 与 Wayfinder beat-02
- 执行：judgment:看纸张素材是否保留纸感边缘

## concept-film · 概念电影

### S14 一镜一关系

- 做法：每个镜头只承载一个关系或一个变化；运动、色彩、尺度、构图都服务这个关系，不并列多个同等焦点。大部分时间保持克制，把更强的视觉手段留给关键关系。
- 证据：参考片 · 全片
- 执行：judgment:用一句话说出本镜关系，再看是否有元素不为它服务

### S15 抽象关系转成空间动作

- 做法：把概念转成位置、方向、距离、包含、聚散、先后等空间关系，让观众通过运动理解概念，而不是靠文字解释；不规定具体动作形式。
- 证据：参考片 · Flow Matching / Reflow 段
- 执行：judgment:去掉字幕，画面是否还能读出这个概念

### S16 空间连续与可导航

- 做法：镜头或场景之间保持可理解的空间关系；优先用连续运动、方向匹配、视线引导维持方向感；允许换页或切镜，但切换后观众仍知道现在在哪、在看什么。
- 证据：参考片 · 全片
- 执行：judgment:每次切换后，观众是否还能说出当前位置与对象

### S17 真实与抽象互为证据

- 做法：抽象图形负责解释，真实素材负责可信；两种素材都可以使用，按内容需要交替或叠加，不设固定频率；真实素材要可读、与论点相关，不做装饰。
- 证据：参考片 · ComfyUI / 论文 / 书法段
- 执行：judgment:真实素材是否可读、是否支撑当前论点

## 边界：元素级处理不进这里

单个元素的特殊处理由本片 design 文档决定，不写成风格规则。例如某个元素是 Skill 或命令的名字，就用打字机出现，给"正在调用它"的感觉——这是那个元素的处理方式，不是一种风格。
