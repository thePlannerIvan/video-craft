# 素材来源与准入（montage 路线）

> 什么时候读：片型是 **montage**，手上有了一批候选素材（档案影像 / 实拍 / 照片 / 截图），
> 要在排镜头**之前**决定「哪条能用、哪条必须弃」。这一页只回答判据，**判据以本页为准**；
> 操作顺序与完成标准（素材清单 → 镜头表 → 渲染 + 体检）见 [montage-route.md](montage-route.md)，
> 画框与素材带的铺法见 [frame-spec.md](frame-spec.md)。

2026-11 哈雷片的第一版没有这份判据：水印能不能用全靠临场拍板，结果成片里留了 4 处档案角标，
而 VH1 台标 / Huntley 整屏水印 / 烧录时间码的素材整条弃用——只有过程，没有可复用的规则。
差别不在「看起来脏不脏」，而在有没有过下面几条判据。

## 来源与授权

第三方平台上传的档案影像**属于他人上传**，不是公共素材库。登记时记的是原本是谁发的
（机构官方号 / 搬运号 / 二创片），不是转发链上的那一条。

- **出处列必须写 URL + 平台/账号 + 授权状态**，例如
  `youtube.com/watch?v=…（VH1 官方号；授权待确认）`。只写“YouTube”不算出处。
- **Skill 不替作者做版权判断**，也不给“合理使用”之类的结论。它只要求把
  **出处 + 风险**写进素材清单，由作者定这一条是 可发布 / 仅内部审看 / 待确认。
- **对外发布前逐条核对授权**：拿清单的出处列过一遍，没出处的项补上或换掉。
  内部审看版用了“待确认”素材，对外版不能沿用同一份声明。
- 没有 URL 的素材不进镜头表——和“写不出一句话”同等级，属于没看清来源。

## 水印分级

判据一句话：**能否在不损失构图的前提下裁掉 / 移到画框外**——不能就是不可用。
覆盖面积和位置是这条判据的可观察代理，不是规则本身。

| 等级 | 判据 | 典型来源 | 处理 |
|---|---|---|---|
| 不可用 | 覆盖面积大到裁完构图就废；或落在画面中央 / 字幕安全区 / 花字位；或本身就是被摄内容的一部分（平台 UI、促销卡、烧录字幕） | 整屏水印（Huntley 那种铺满画面的半透明标）、频道台标（VH1 / K / BLOCKHEAD）、烧录对白字幕、烧录时间码、Instagram/TikTok 截图（带赞评转与账号名）、促销卡（“CLICK TO DOWNLOAD” / “SUBSCRIBE”） | 弃用。裁不掉、遮不住，压在任何一屏上都读成“盗来的素材” |
| 可用但必须登记 | 贴在画面角上、面积小，落在画框的留白里，裁掉或留在画框外都不动主体 | 档案机构小角标：British Pathé 公鸡、AP、Huntley 类角标 | 清单登记位置（如“右上 AP”）；交付说明写「画面含档案台标」；画框同角不再放东西 |

三条边界，最容易被读错：

- **按版本判断，不按机构名判断。** 同一机构可能既有整屏水印版也有小角标版：
  整屏版整条弃用，小角标版登记后可用。
- **小 ≠ 可用。** 角标正好压在字幕安全区或花字位上就按不可用处理——它比“小”更坏，
  因为会和字幕抢同一块像素。
- **不要靠后期把不可用救回来。** 裁切、模糊、遮挡、加暗角都在改画面证据，
  且比重找素材贵；糊掉的水印仍然是脏点。

哈雷片成片里的 4 处档案角标是合格结果，但它们**必须写进交付说明**；
被弃用的素材不是“运气好没用到”，是过不了这一条判据。

## 时代与画质

| 项 | 判据 | 处理 |
|---|---|---|
| 时代 | 画面里可辨识的时代证据（车型、服饰、街景、字体、黑白/彩色/褪色）与这句口播说的年代一致；观众能从画面上读出年代 | 不一致就换素材；确实要用通用画面时，`note` 写明“X 年代通用画面”，讲述里不声称“这就是那年那台车” |
| 分辨率 | 横屏 ≥360p（640×360）才能铺满 1080 宽的素材带——放大 1.7 倍，配合颗粒与调色仍可读；低于 360p 放大超过 2 倍，观众先看见“糊” | 低于 360p 只做小窗 / 局部插入 / 档案质感特写，不铺满 |
| 宽高比 | 4:3 与 16:9 混用要有统一版式（铺法见 [frame-spec.md](frame-spec.md)）；同一段落内不交替 | 交替切比例会读成“素材乱凑” |

时代判据的典型错误：讲 1950s 却交 1925 的机器特写，还在解说里说“就是那个年代”。
画面承担的是证据，证据说错年代比画质差严重得多。

## 入点与可用时长

每条素材登记**入点 + 可用秒数**，剪辑从入点起连取 2–7 秒。

- **入点 +7 秒内不能有切镜 / 水印漂入 / 片头卡**：7 秒是最长取用长度，
  入点后这 7 秒必须一直是同一内容、同一干净程度，剪多长都安全。
- **可用秒数 = 连续同一内容的窗口长度**，扣掉片头卡、转场、漂入的台标。
  窗口不足 2 秒的不进镜头表（剪不出可读的镜头）；超过 7 秒没问题，只取前 7 秒内。
- **一个素材文件可以有多个可用段落**，各带自己的入点，分别登记。
- 入点不落在淡入淡出/转场的边缘，否则起切会闪。

判据一句话：**从入点往后随便取 2–7 秒，都必须还是这段内容。**

## 登记格式

清单骨架由 [helpers/scan_materials.py](../helpers/scan_materials.py) 生成，
固定六列：素材 / 时长·尺寸 / 可用段落 / 画面一句话 / 水印·台标 / 出处。
后四列的填法：

| 列 | 怎么写 | 反例 |
|---|---|---|
| 可用段落 | `47.0–58.5（11.5s）`：绝对秒数 + 长度，一行一个可用段 | “开头那段”“一分多钟那里” |
| 画面一句话 | 主体 + 景别 + 色调 + 有没有文字，例如“1969 飞车党车队在荒漠公路，中景，褪色彩色，无文字” | “很有感觉”“哈雷素材” |
| 水印 / 台标 | 位置 + 等级 + 结论：`右上 AP 小标，可用须登记` / `整屏 Huntley 水印 + 左下时间码，不可用` | 留空（留空等于没看，不等于没问题） |
| 出处 | URL + 平台/账号 + 授权状态（见「来源与授权」） | “网络” / 只写平台名 |

- **写不出一句话的素材不要进镜头表。** 写不出主语说明还没看清它是什么，
  进了镜头表就是一镜黑或一镜废话。真需要空镜时，`note` 写“空镜 + 用途”，
  并确认它是真画面而不是只有画框底图。
- 登记完的判据是**可复现**：后来的人只看清单，就能解释每一条为什么可用/不可用，
  不必再拖一遍时间轴。

## 失败处理

找不到干净源时，**如实报缺口**，不要用同类素材冒充。

- 报缺口要说清：哪一句口播、缺哪一类画面、为什么现有素材不能用；给作者两个选项
  （换画面 / 改讲述），由作者选。
  例：口播说“一家人围着电视”，全网只有带整屏台标的版本 → 换成收音机或客厅静物，
  或把讲述改成“围坐在一起”。不硬凑。
- **不冒充**：不拿别的年代配“这就是当时”，不拿别的车型配“那台车”，
  不用 AI 生成或别的影片片段顶档案。生成素材不是证据，若要使用须标明身份
  （见 [media-first.md](media-first.md)）。
- 缺口留在素材清单与交付说明里，不要等到交片时才发现少一镜。

## 一条总判据

每条素材进镜头表之前，必须能回答四件事：**出处与风险、水印等级、入点 + 可用秒数、
一句话画面**。少一件就回帧带再看一遍——这四件全齐，排镜头才是选择，不是赌。
