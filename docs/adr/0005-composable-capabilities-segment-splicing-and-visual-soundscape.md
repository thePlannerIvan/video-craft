# 0005 · 能力组合正交架构、按段分流拼合与双轨声景分离

**Status**: accepted

我们决定废除互斥的三选一「生产模式」路由与「人物轨捆绑音效、画面成片强制零音轨」旧约，正式确立以「剪口播」为固定底座、可自由叠加零至三项正交画面能力（`footage` / `motion` / `screen-demo`）且与「画框」完全解耦的能力组合架构；确立统一执行分镜 `storyboard.json` 驱动审阅期代理预览与交付期按段分流拼合（HyperFrames 仅渲染动效与叠层段，纯视频与录屏段由媒体工具链直切后毫秒级拼合）；并将声音彻底拆分为专属 `人物成片.mp4` 的「人声润色」与专属 `画面成片.mp4` 及独立 `画面音效轨.wav` 的「画面声景」。本裁决部分取代 `ADR-0002` 的三选一模式边界与 `ADR-0004` 的双轨音频归属约束。

## Considered Options

- **继续保留三选一互斥生产模式并扩展特例开关**：会导致混合视频（如竖屏商业广告混剪 + 随口播演化的 3D 思维模型 + 3D 卡片）不断堆砌胶水脚本，且风格规则继续错误锁死能力组合与画框。
- **全片统一进浏览器逐帧录制并延续人物轨混入动效音效**：纯实拍与录屏段被迫经历无头浏览器慢渲染并触发视频图层黑屏风险；动效音效与广告原声底噪错配在人声润色流程里，无法在审阅期试听开关画面声景。

## Consequences

- **能力组合与轻量 Look-Dev Gate（部分取代 `ADR-0002`）**：`风格` 仅管审美语言与偏好画框，不再锁死能力组合；无现成静态参考页而开启 `motion` 时，全片编码前先过极轻「轻量样镜定调」并采用随口播演化的「思维模型动效」，长篇静态排版按需请排版工具介入。
- **按段分流渲染与直切拼合**：下游以 `storyboard.json` 为唯一机器真源；审阅期实拍以轻量代理进活舞台，交付期仅 `motion` / `card-deck` / 显式叠层段走 HyperFrames，纯 `footage` 与 `screen-demo` 由媒体工具直切高清母版并毫秒级拼合进 `画面成片.mp4`。
- **双轨声音分离与无损封装（部分取代 `ADR-0004`）**：`人声润色` 默认内置停顿重吸气声衰减与暖声校准，专归 `人物成片.mp4`；`画面声景`（动效起伏音效 + 自动筛分避让与人声侧链闪避后的可选原声底噪）审阅期可试听并开关底噪，交付时存在声景则无损封装进 `画面成片.mp4` 并同出 `画面音效轨.wav`（无声景需求时画面成片仍合法保持 `0` 音轨）。
- **向后兼容边界**：存量历史项目的 `production_mode` 元数据与既有分轨归档产物保持只读扫描与兼容，不重写已归档老片。
