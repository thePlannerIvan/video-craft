# Spec: Video Craft v2 — 清仓重构、四档视觉语法、声画升级与极简交互

## Problem Statement

创作者在使用现有视频制作工具链进行日常出片时，面临四个集中爆发的问题：

1. **新画面制作被旧静态页模板绑死，且实机演示混排缺少清晰护栏**：旧制作入口默认强制逐元素搬运静态演示页，导致生成的动效画面塞满小字与框线，手机端观众看不清字；缺少看人留白呼吸档位与常见渲染陷阱拦截，容易出现发光线条隐身、字体未注册卡死或切章残留；同时在技能分享等视频里，人物独立一轨而画面成片往往同时包含动效和实机录屏，既不能把百兆高清录屏直接塞进无头浏览器渲染导致卡死发糊，也不能让画面门禁对录屏界面小字误报警。
2. **工具内部历史包袱沉重、术语与上级总控分裂**：长期演进积累了海量零散脚本、重复或冲突的参考手册、已退役旧路线存档以及已迁往上级的风格提取逻辑；上下游对生产模式的叫法不一、画框尺寸在多处各自定义，导致模型每次进场都在噪音中试错。
3. **人声缺少胸腔厚度与克制音效节奏**：实测口播原声在低中频存在房间箱音浑浊、胸腔基频偏薄与清晰度滚降，现有默认流程既未介入补偿，也缺乏轻度播客压缩与克制卡点音效来托住画面节奏。
4. **交互页面拖动手感生硬、窗口适配失灵且充斥工程废话**：逐字剪辑页跨字缝拖动极易中断丢失选区；画面审阅页在半屏或窄侧栏下排版挤压溢出；两个原本功能简单的页面堆满工程字段词与解释性文字，增加认知负担。

## Solution

以「先打扫屋子、再升级声画表现与极简交互」为原则重构视频制作技能，整体保持在既有渲染底座与稳定底层算法之上演进：

- **打扫屋子并与制片总控 1:1 对齐**：移出历史存档、数学动画子工具、已迁往上级的风格提取写入与零引用孤立工具；将八十余个散乱脚本收口为约十个顶层命令入口并隐藏内部共享件；将三十五份碎片手册精简合并为约十一份核心文档；统一领域词汇并把人物位与字幕安全区收口为单一画框几何真源，同时确保无私有风格库时的独立回退。
- **建立四档视觉语法、实机演示同轨无损拼合与构建期统一门禁**：废除强制照搬静态页的旧闸门，改为按口播语义在「只看人留白 / 逻辑演进主角大字 / 理论高亮拆解 / 实机演示录屏」四档之间自由混排的视觉分拍表；动效段由浏览器渲染，实机演示段预览走轻量代理、交付直接由视频引擎从高清原录屏裁切拼合进同一份画面成片；统一门禁按档分流，精准拦住动效小字、死静与渲染陷阱，同时豁免录屏界面不误报。
- **固化实测听选的 C 档播客浑厚人声预设与极克制本地音效**：把盲听锁定的 C 档人声声学链设为默认人声处理并保留一键纯干声开关；新增内置精选本地素材的极克制音效轨，严格限制触发点、触发频率与人声下方避让音量。
- **按「零工程文字、零解释文字、简单好看」精修两处交互页并做真实片验证**：重做逐字全局指针拖选与审阅页容器自适应布局，清退所有工程术语与过程说明文案；最后在制片总控补充轻量节奏提示，并拿《非遗三个圈》真实副本走通端到端对照验收。

## User Stories

1. 作为创作者，我希望把历史存档与不再使用的数学动画子工具彻底移出主目录，以便模型执行任务时不再读入干扰判断的过时内容。
2. 作为创作者，我希望把八十余个零散工具收口为约十个清晰顶层入口、把三十五份碎片手册合并为约十一份结构化文档，以便维护和调用时一眼看清全部主路径而不破坏既有底层稳定性。
3. 作为创作者，我希望剪辑制作层的生产模式与上游制片总控完全 1:1 对齐并建立统一词汇表，以便跨环节交接无需反复换算新旧名称。
4. 作为创作者，我希望公开版本的剪辑制作能力在没有挂载私有风格库或本地制片总控时仍能自动回退至内置默认规范，以便独立开源仓库也能完整跑通。
5. 作为创作者，我希望现有已经很稳定的口播剪辑主线（词级转写、逐字审阅、剪辑单导出、实测时间轴与文章优先字幕）完整保留，以便日常剪片质量不出现任何回退。
6. 作为创作者，我希望现有的蒙太奇剪辑主线保持稳健并在入口处对齐制片总控，暂不提前引入混合动效贴纸等试验功能，以便专注先把高频主线改透。
7. 作为创作者，我希望人物孔位与字幕安全区只有一个权威几何来源，以便调整画框时只需改一处就能同时约束画面构建、渲染与审阅展示。
8. 作为创作者，我希望新画面制作不再强制逐元素照搬静态参考页，而是把参考页仅作为造型与配色灵感，以便彻底摆脱「会动的演示文稿」观感。
9. 作为创作者，我希望口播中需要讲故事、铺垫观点或停顿留白时可以明确选择只看人模式，以便画面大方呼吸而不硬凑无意义的动画或打字。
10. 作为创作者，我希望在讲解「三个圈、洞察、定位、因果或对比」时默认进入逻辑演进模式，一屏只呈现一到两个视觉主角与极少大字锚点，以便观众在手机上也能一眼看懂核心关系。
11. 作为创作者，我希望只有在讲解完整理论模型或框架清单时才开启理论拆解模式，并强制正在口播的那一项高亮、其余项自动压暗，以便信息较多时依然突出当前焦点。
12. 作为创作者，我希望在技能分享或软件操作视频中把实机演示录屏作为独立画面档位与动效在同一份画面成片内混排，人物保持独立一轨，预览走轻量代理而交付由视频引擎直接从高清原录屏切出并启用清晰文字编码拼合，以便既不卡死渲染又保证界面文字锐利清晰。
13. 作为创作者，我希望构建期检查自动拦截动效画面在 1080p 画布下小于 32px 的字号，以便彻底杜绝粉丝反馈「精致但看不清字」的问题。
14. 作为创作者，我希望构建期检查自动捕获动效与逻辑演进片段连续静止超过六至八秒，以及任意主体侵入人物位或字幕安全区的情况，以便在渲染前及时补救节奏与遮挡。
15. 作为创作者，我希望构建期检查对实机演示录屏档自动豁免 32px 界面字号与网页静止告警，改为校验录屏源存在、入出点未越界、无黑帧且不侵入人物与字幕安全区，以便录屏片段不会触发无意义误报警。
16. 作为创作者，我希望构建期检查自动拦截矢量横纵线未设全局滤镜坐标系导致的隐身、样式引用未注册本地字体导致的预览卡死、以及跨章切换后的残留元素，以便不再靠肉眼反复返工踩同一个坑。
17. 作为创作者，我希望渲染一致性核验在快速转场瞬间允许相邻帧对齐与全分辨率亮像素复核，以便减少因降采样模糊引发的误报警。
18. 作为创作者，我希望系统默认启用我盲听选定的 C 档「播客浑厚」人声处理预设，自动削减房间闷糊箱音、补强胸腔厚度、柔和提亮清晰度并压制齿音，以便直接输出饱满耐听的口播人声。
19. 作为创作者，我希望人声与混音步骤保留明确的一键绕过开关，以便特殊场景下随时能够导出未经 EQ 与压缩的纯干声。
20. 作为创作者，我希望混音环节内置六至十个经免署名商业许可筛选的本地柔和音效素材，且不默认联网自动乱搜音效，以便成片声音克制可控且离线可复现。
21. 作为创作者，我希望音效只在切章、核心概念揭示与关键反转时轻点一下，全片平均每十五至二十五秒最多触发一次，以便绝不抢戏也不显得廉价吵闹。
22. 作为创作者，我希望音效默认压在人声下方十八至二十二分贝，并在审阅页里实时可听、支持一键纯干声关闭，以便听着别扭时随时一键撤掉。
23. 作为创作者，我希望逐字剪辑页支持跨字缝与行缝连续平滑拖选、支持按住 Shift 单击连选整段、拖近边缘自动平滑滚屏且鼠标移出窗口不清空已有选区，以便删改几十句口播时一次拖准。
24. 作为创作者，我希望画面成片审阅页能根据浏览器窄侧栏、半屏与全屏窗口自动等比缩放舞台与分栏布局并保持顺畅滚动，以便在任何窗口大小下都不会被裁切或遮挡按钮。
25. 作为创作者，我希望逐字剪辑页与画面审阅页拿掉一切工程术语与解释性说明文字，只靠干净直观的控件和交互反馈传达状态，以便操作界面简单好看、打开就能直接上手。
26. 作为创作者，我希望上游制片总控在陪我共创口播时给出一句轻量提示，提醒自然考虑哪些段落看人留白、哪些适合图形演逻辑、哪些要亮模型拆解、哪些衔接实机演示，以便写稿时自然兼顾节奏而不必为动画硬改口播。
27. 作为创作者，我希望重构完成后用《非遗三个圈》项目副本端到端实跑一遍并对照验收，以便亲眼验证新版在画面聚焦度、声音浑厚度与页面手感上的真实提升。
28. 作为创作者，我希望全部验证通过后再经统一检查同步至三个本地运行时目录，并严格通过密钥闸门同步至公开代码仓库，以便日常使用与开源发布一致可靠。

## Implementation Decisions

### 三条主线、公共底座与领域术语对齐

- 对外核心流程收敛为与制片总控完全一一对应的三条业务主线加一个公共底座：口播剪辑主线（对应纯口播生产模式，同时作为所有真人出镜视频的共同第一步）、蒙太奇剪辑主线（对应实拍与档案混剪模式）以及新画面制作主线（对应关键帧与图形动画模式，含动效与实机演示同轨混排），共享声音处理与混音、统一画框约束、统一审阅工作台以及成片交付核验四个公共能力。
- 新建统一领域词汇表与关键架构决策记录：明确以生产模式取代旧有的片型、图形路、十步页面路线及退役构思系统称谓；将旧有静态关键帧项目保留静默兼容通道但移出默认主入口；明确保留既有的无头浏览器渲染底座，不把工程成本投入重写另一套视频引擎，而是吸收结构化视觉隐喻与音画卡点的方法论。

### 屋子清扫：废料移出、入口收口与手册精简

- 彻底清退历史包袱目录与失效模块：整体移出已退役的旧实现存档区与独立的数学动画子技能；删除已明确归口上游制片总控的风格提取与风格库写入工具；清理已废除路线的兼容转发壳与零引用且无回归测试保护的孤立脚本；在精简版开源署名说明中保留必要的第三方版权致谢，并清除剩余模块与测试用例中对已移出目录的死引用。
- 顶层命令十合一与内部实现隔离：将八十余个混杂工具整合收口为约十个高内聚顶层命令行入口，涵盖口播剪辑总入口、人声诊断与预设处理、音画混音唯一出口、时间轴派生与字幕导出、画框配置与预览、新画面视觉分拍表、统一画面构建体检门禁、蒙太奇剪辑总入口、审阅构建与反馈收件、以及成片合成与交付核验；其余约六十个共享基础模块与底层实现整体下沉至内部私有包中，并通过轻薄兼容转发保持全部既有测试无缝通过。
- 文档层压缩归并：将三十五份碎片参考手册合并精简为约十一份现行手册，彻底退役过时的交接与旧模板说明书，并将冗长的历史维修与踩坑清单剥离归档过时条目，仅留存当前仍然生效的硬约束与高频陷阱。

### 开源独立性与画框几何单一真源

- 公开独立回退接口：风格解析入口保留轻量只读能力，优先读取外部挂载的风格库或上游制片总控传入的上下文包；在开源独立运行环境下未检测到任何私有库或上游总控时，确定性降级至内置通用默认风格与画框基线，不因缺少私有目录而阻断流程。
- 画框单一几何源收口：将分散在视觉重排配置与画框工具两处的画布分辨率、人物孔位矩形及字幕安全区边界收口为单一权威几何定义；画框模块负责提供统一读取接口与校验输出，保证画面舞台生成、构建期入侵检查、蒙太奇落位渲染、实机演示落位裁切与审阅页叠加框读取完全相同的像素坐标。

### 新画面四档视觉语法与实机演示同轨契约

- 废除逐元素抄写闸门：改版视觉分拍表校验入口，取消强迫把静态演示页里每一个文字与图框逐条绑定到口播字词的强制校验，将原有静态关键帧与参考图明确降级为配色、比例与造型风格参考。
- 四档视觉语法契约：视觉分拍表要求每个口播语义段在同一条实测时间轴上明确声明以下四档之一，允许自由混排且人物轨保持独立：
  1. **只看人留白档（talk-only）**：适用于故事引入、观点铺垫、金句与节奏过渡；全画面保留人物或干净景别，不强制叠加图形与文字卡片。
  2. **逻辑演进档（logic-diagram，默认主力）**：适用于阐释集合关系、商业洞察、定位、因果推导与对比；每屏严格限定一至两个主视觉图形及极少量核心大字锚点，依靠图形位置、连线与状态演进陪跑十至二十秒口播，禁止整句上屏或机械打字效果。
  3. **理论拆解档（theory-board）**：适用于讲授经典多维模型或步骤清单；允许保留较多理论文字与原有框架排版，但时间轴必须实现讲授当前条目时对应节点高亮放大、其余非焦点条目自动降暗退后。
  4. **实机演示录屏档（demo-footage）**：适用于技能分享、软件操作与终端实机演示；同一条时间轴上支持与动效段无缝交替出现，人物继续留在独立人像轨。审阅预览阶段仅在时间轴槽位挂载轻量低码率代理片以保证秒开不卡死，严禁把百兆高清原录屏放进动效资产目录；正式交付阶段由动效引擎只渲动效段及可选轻量透明圈注/角标层，由底层视频合成器直接读取高清原录屏按实测入出点裁切或变速并启用屏幕清晰文字保护编码，与动效段按帧网格无缝拼合进同一份画面成片。

### 构建期统一画面质量门禁

- 合并原有活舞台断言、动画目标核验与新增表达力规则为单一构建期画面体检入口，在预览启动与正式渲染前阻断不合规构图，并按视觉分拍档位自动分流校验：
  1. **通用与动效档检查**：逻辑演进与理论拆解档在 1080p 画布下关键正文与标签计算字号低于 32px 时直接拦截；非只看人、非实机演示段连续无视觉状态或属性变化超过六至八秒时强告警；任意非字幕视觉元素外接包围盒侵入统一画框人物位或字幕安全区时拦截；纯水平或纯垂直矢量线条挂滤镜但未显式指定全局坐标系滤镜单位时拦截（防止零宽高边界盒裁切导致隐身）；样式引用未显式声明注入的外部本地字体名时拦截（防止预览超时卡死）；跨章时间切换点后上一章根节点未清零退场时拦截（防止残留叠影）。
  2. **实机演示档豁免与专项检查**：对标记为实机演示录屏档的片段，自动豁免 32px 字号底线与网页静止时长检查，转而强制校验录屏源文件存在、声明入出点区间不越界、抽取画面无全黑帧，且演示画面显示区落位不侵入人物孔位与字幕安全区。
  3. **转场采样容错**：渲染一致性采样对比在检测到单帧降采样相关度偏低但落在转场变化窗内时，自动向前后各扩展一帧并以全分辨率亮像素数量与误差重核，避免对正常快速滑入转场发出误报。

### 个人人声预设与极克制本地音效管线

- 固化 C 档「播客浑厚」人声默认预设：将盲听确立的声学处理链内置为人声处理模块默认配置，完整参数为 65Hz 高通滤波切净超低频杂讯、115Hz 提升 3 分贝补充胸腔厚度、245Hz 削减 3.5 分贝消除房间箱音浑浊、3.2kHz 提升 2.5 分贝保证人声轮廓清晰、9.5kHz 柔和搁架提升 1.8 分贝补齐空气感、5.2kHz 至 8.2kHz 侧链动态压缩压制尖锐齿音、辅以温和播客压缩器并经双遍响度归一化输出为 -14.0 LUFS 与 -1.5 dBTP；同时保留显著的一键绕回纯干声开关。
- 极克制本地音效混音扩展：在唯一混音出口内扩展声明式本地音效轨输入接口，随包精简内置六至十个经免署名商业许可筛选的克制短音效；混音逻辑强制三条硬护栏——仅响应切章、核心概念揭示与关键反转三类节点且全片平均密度不高于每十五至二十五秒一次（超密直接拒绝或告警）、音效峰值自动衰减并压在人声下方十八至二十二分贝区间防止掩蔽口播、且在混音输出与审阅页内提供一键纯干声剥离能力；在线音效搜索能力不进主链路，仅作可选手动补库手段。

### 零工程文字的极简交互页升级（逐字剪辑与画面审阅）

- **极简信息纯度原则**：对逐字剪辑页与画面审阅页进行全面界面语言净化——彻底清除页面内一切工程内部状态词、流程步骤提示、技术字段名称、快捷键长说明及解释性副标题；功能状态与操作引导全部收进克制图标、极简两到三字动词、统一高对比色彩状态与直观悬停微反馈中，同时完整保留原有审阅桥通信标记与宿主兼容能力，确保外观简单干净好看。
- **逐字剪辑拖拽手感重写**：将原有易断触的文字元素悬浮监听重构为基于全局指针捕获的连续拖拽状态机；指针移动经过字间隙、标点与段间行距时按当前视口坐标到同段相邻词盒的几何最短距离连续吸附选区；补充按住 Shift 单击的连续区间选中、拖至列表顶部或底部自动触发容器平滑滚动、以及指针移出浏览器边界时不清空已有待确认选区。
- **画面审阅页窗口自适应布局**：清除样式表中多套互相冲突覆盖的固定列宽断点，改造为容器宽度自适应栅格与可拖拽分隔中轴；中央 16:9 播放舞台改为同时受限于当前父容器可用宽度与视口剩余高度的等比贴合容器；在宽屏、半屏并排及窄侧栏三种尺寸下保证舞台零溢出、操作控件不折行遮挡，并在窄宽度下自然退化为可顺畅滚动的纵向单栏布局。

### 上游制片总控轻联动

- 在上游制片总控的口播共创指导中仅增补一句克制提醒：引导创作者在梳理关键转折、机制拆解与操作演示段落时自然评估节奏是否适合看人留白、逻辑图形演进、理论面板亮显或实机演示录屏，绝不要求口播文稿为配合动画强行加入动作词或打乱说话逻辑。

## Testing Decisions

### 外部行为测试原则与最高测试接缝

- 所有新增与改造能力均坚持仅测试可观察外部行为，严禁针对内部私有函数或重构前后中间状态写脆弱绑定测试；测试数据与工程运行全部通过显式路径注入隔离在临时沙箱或项目副本目录中。
- 依托四条最高层测试接缝完成全量回归与新能力验收（延续既有黑盒单元测试、模板安全护栏、规范结构校验器与行为评估集先例）：
  1. **顶层 CLI 进程黑盒接缝**：通过子进程调用收口后的顶层命令行入口验证退出码、标准输出诊断、音频指标与输出产物；
  2. **构建期视觉门禁与合成验收接缝**：注入构造好的合格与违规舞台输入（含动效、留白与实机演示录屏混合时间轴），通过构建体检进程入口、交付合成入口与审阅构建入口验证拦截精确度与成片可播性；
  3. **真实无头浏览器交互与零工程文案接缝**：在真实浏览器渲染上下文中驱动多视口尺寸渲染与鼠标指针事件，并断言页面可见文本纯度；
  4. **真实项目端到端样本与跨端发布对账接缝**：在《非遗三个圈》项目副本、技能库全量发布校验器及远端镜像核对脚本上验证最终交付与发布一致性。

### 顶层命令与构建门禁黑盒验收

- 清仓收口后跑通全量现有单元测试套件与行为评估集，保证口播剪辑、时间派生、文章优先字幕、蒙太奇体检与交付核验全部零回归。
- 针对构建期统一画面门禁逐项构造正反例夹具，分别验证动效段小于 32px 字号、静止超八秒、侵入人物或字幕区、缺少全局滤镜坐标系的横纵矢量线、未注册本地字体引用、跨章节点未清零残留均返回非零退出码并定位具体出错元素，同时验证快速滑入转场在相邻帧复核下不再误报；对实机演示录屏档验证小字与静止检查自动豁免且对缺源、入出点越界、黑帧与画框侵入准确拦截。
- 在临时沙箱验证「动效段 + 实机演示录屏段」同轴混排交付：生成一份人物独立音视频轨与一份由高清原录屏和动效段无缝拼合的画面成片，核验时长帧格、清晰文字编码标志、音频分离状态及首中尾无黑帧。
- 针对声音链运行频谱与响度计量验证：校验 C 档预设输出稳定落在 -14.0 LUFS 允许误差范围及真峰值安全线以内，低频厚度较原声明显提升、齿音峰值收敛；校验一键纯干声参数确实跳过处理；校验混音器拒绝超高密度音效输入并实测音效轨保持在人声下方预定分贝压低区间。

### 交互页浏览器行为与零工程文案验收

- 使用无头浏览器加载逐字剪辑页样本，模拟按住指针跨越字间空隙、标点间隙与跨行区域连续拖选并拖动至可视区边缘外，断言选区连续不断裂且移出窗口后选区保留；模拟 Shift 单击区间连选并提交，核对产物数据精确命中预期词区间。

- 在两条交互页全部可见文本节点上执行工程术语与冗长说明黑名单扫描，确保无过程性工程字眼或大段解释文字泄露到用户可见界面。

## Out of Scope

- **蒙太奇混合动效贴纸叠层**：档案快切片上的局部透明动效印章与批注卡留待后续实际制作蒙太奇项目时再专门设计，本轮不做。
- **渲染引擎迁移或双引擎支持**：不向 Remotion 迁移，也不并行维护第二套引擎实现。
- **审阅桥公共协议与核心时钟重写**：不改动审阅桥公共宿主页通信协议及播放器核心时钟逻辑，仅优化上层样式布局、文案纯度与拖拽输入手感。
- **默认联网自动搜索音效**：不把实时网络检索作为默认流程，在线检索仅保留为独立可选手工补库方式。
- **稳定剪辑与转写核心算法重构**：不重写流式语音识别接口、静音包络剪点对齐与文章优先断句底层算法。
- **上游幻灯片工作台内部接口改造**：本轮只调整制片总控的一句轻量口播节奏提醒与对齐双方术语，不动幻灯片工具自身排版机制。
