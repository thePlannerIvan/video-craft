# 视听能力导航：按表达目的选，不按熟悉工具选

Idea 在概念发想时、Craft 在接手和视觉遇到瓶颈时读本页。这里只提供能力导航；原理和实现留在原资源，选中才读。内置表示本 Skill 带文件，不代表运行依赖已安装；外部 Skill 先按当前环境的 Skill 目录定位，未安装不假装可调用。archive/ 是历史参考，不作为默认制作入口。

## 从观众要看见的变化出发

| 表达任务 | 可考虑的表现机制（不是固定答案） | 首选读取位置与边界 |
|---|---|---|
| 证明真实发生过什么 | 原始操作录屏、局部聚焦、前后匹配、证据与解释并置 | 内置 [media-first](media-first.md)；先找真正发生动作的区间 |
| 让差异可感 | 同位对比、遮罩揭示、差值累积、物件变形、结果回溯 | 外部 `hyperframes-animation` 的 rules-index.md，选匹配条目；实现前读 `hyperframes` / `hyperframes-core` |
| 数量、筛选、规模与分布 | 个体聚成整体、逐项剔除后重排、分组迁移、数据驱动图形 | 外部 `hyperframes-creative/references/data-in-motion.md`；数据来自本项目，运动不能编造关系 |
| 解释流程、系统、因果 | 状态推进、路径追踪、局部展开、同一场景内改变关系 | 外部 `hyperframes-animation/techniques.md` 或 blueprints-index.md；需要数学/算法严密变换时读内置 [Manim](../skills/manim-video/SKILL.md) |
| 空间、层次、结构 | 2D 分层、剖面、相机穿行、3D 对象关系 | 外部 `hyperframes-animation/adapters/three.md`；先做一个可 seek 的最小试片。只有空间关系有意义才承担 3D 成本 |
| 强调语气、情绪、转折 | 动态字体、停顿与揭晓、节奏剪接、画面与声音反差 | 外部 `hyperframes-animation` 的文字类 rules、`hyperframes-creative/references/beat-direction.md`；重点文字不等于整段字幕 |
| 真实素材与抽象解释结合 | 页面拆层、标注、原图转为可理解模型、再回到证据 | 内置 [media-first](media-first.md) + [composition-craft](composition-craft.md)；来源与示意身份分清 |
| 氛围、质感与声音 | 素材处理、图像、音效、音乐、声音引导注意 | 外部 `media-use`；按需读取对应类型和 provider 配置，授权、账号与费用另行核实 |
| 风格与全片一致性 | 定制视觉语言或现有主题种子、字体/色彩/运动节奏统一 | 内置 [themes](themes.md) 及 visual/themes；外部 `hyperframes-creative`。主题不是创意方案，不必为了使用库存套一个不合题的主题 |
| 已有组件或复杂动效实现 | 复用可匹配的组件、模板、插值与 seek 方案 | 外部 `hyperframes-registry` 查可用组件；`hyperframes-keyframes` 处理复杂插值。匹配表达后再取资源，不从模板倒推创意 |
| 静态证据、安静阅读 | 好的排版、裁切、逐项高亮、必要停留 | PIL/HTML/真实素材即可；静止可以是有意设计，复杂工具不自动更好 |

## 有限检索与选择

1. 先用一句话写观众应看见的关系/变化，核对真实素材和作者已定动作。
2. 从表中选最相关的能力；通常只展开 1–2 类资源，每类读少量命中条目。复杂机制有理由再扩大，不全库加载。
3. 对关键场景至少在内部比较两个**机制不同**的表达：它增加了什么理解或感受、要什么材料、风险在哪。简单/已有明确决定的段落直接执行，不逐段凑方案。
4. 在 production-plan 只留最终选择、资源入口与一条理由；被淘汰方案只有影响作者决定时才展示。引入陌生渲染器或 adapter 时先试一个短片验证依赖、seek 和输出接口，再铺开。
5. 同一套能力和视觉语言复用到同类段落；新工具只在现有方法无法完成关键表达时引入。不要把“能力充分”理解为每片同时用所有引擎。

HyperFrames 是主要编排路径，Manim 可作为必要的独立片段来源；已有合格媒体可以直接使用。输出统一回 alpha/opaque 与实测时间契约，不让换引擎产生第二条失控时间线。Remotion 等在本环境没有确认的资源不算现成能力；确有必要时再核查。

## 给 Idea 的轻量咨询

在核心已明确、具体表现尚未锁定时，Idea 读取本页并为有潜力的概念附一条“表现机会”：观众经历什么变化、可用能力、素材前提和待验证点。不要把工具名当创意卖点，不把 API/动效参数提前塞进口播。可行性不确定且影响概念选择时只做一个局部预演；否则把候选表现交 Craft 深化。

这份导航由 Craft 维护，Idea 只保留入口，不复制资源清单。新增资源必须有明确表达用途与可用入口，真实项目验证后标记适用条件；过期入口修复或删除。
